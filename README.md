# Energy Manager (Gen2)

Local daemon that curtails solar production when exporting electricity
costs money, maximizing self-consumption.

## Installation in Home Assistant

1. In Home Assistant, navigate to **Settings** → **Add-ons** (or **Apps**) →
   **Add-on Store**.
2. Click the three dots in the top right corner and select **Repositories**.
3. Add repository URL: `https://github.com/vdvm/energy-manager-gen2-hass`
4. Install **Energy Manager (Gen2)**.
